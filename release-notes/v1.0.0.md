# MoverGUI 1.0.0

Первый публичный релиз Mover GUI.

Mover GUI — компактная Windows-утилита для копирования файлов на удалённые кассы SetRetail по SSH/SCP.

### Возможности

- хранение списка касс и IP-адресов;
- сохранение настроек между запусками;
- поддержка нескольких паролей;
- автоматический перебор паролей при подключении;
- запоминание рабочего пароля для каждой кассы;
- безопасное хранение паролей средствами Windows DPAPI;
- выбор нескольких файлов для отправки;
- Drag & Drop файлов;
- одновременная отправка на несколько касс;
- проверка доступности кассы;
- отображение состояния каждой кассы;
- журнал операций;
- импорт настроек из старого `settings.ini`;
- встроенный PSCP.

### Требования

Для запуска требуется Microsoft .NET 10 Desktop Runtime x64.

.NET SDK пользователю устанавливать не требуется.

### Сборка

Начиная с версии 1.0.0 Mover GUI распространяется как framework-dependent приложение.

.NET Runtime больше не включается непосредственно в EXE, благодаря чему размер программы значительно уменьшен.
