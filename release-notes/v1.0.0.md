## Mover GUI 1.0.0

Первый публичный релиз Mover GUI.

### Возможности

- компактный GUI для отправки файлов на удалённые кассы;
- сохранение списка касс и IP-адресов;
- несколько SSH-паролей с автоматическим перебором;
- запоминание успешного пароля отдельно для каждой кассы;
- защищённое хранение паролей через Windows DPAPI;
- выбор нескольких файлов и Drag & Drop;
- параллельная отправка на несколько касс;
- индивидуальные статусы и журнал операций;
- импорт основных параметров из старого `settings.ini`;
- автономная Windows x64 сборка — установка .NET Runtime не требуется.

### Файлы релиза

- `MoverGUI-v1.0.0-win-x64.exe` — автономный EXE;
- `MoverGUI-v1.0.0-win-x64.zip` — EXE + README + сведения о сторонних компонентах;
- `SHA256SUMS.txt` — SHA256-контрольные суммы.
