# Mover GUI

**Mover GUI** — компактная Windows-утилита для отправки файлов на удалённые кассы SetRetail по SSH/SCP.

Программа создана как более удобная GUI-альтернатива простому BAT-варианту «Мувера»: вместо ручного редактирования `settings.ini` пользователь работает со списком касс, файлами и паролями через один компактный интерфейс.

> Проект не является официальным продуктом CSI / SetRetail и не связан с разработчиками SetRetail.

## Возможности

- хранение списка касс: наименование, IP-адрес и состояние выбора;
- сохранение списка касс между запусками;
- импорт `_IPlist` и `_send_to` из старого `settings.ini`;
- несколько паролей для SSH;
- автоматический перебор паролей, если первый не подошёл;
- запоминание последнего успешного пароля отдельно для каждой кассы;
- хранение паролей в зашифрованном виде через Windows DPAPI;
- настройка SSH-логина и порта;
- настройка удалённого каталога назначения;
- добавление нескольких файлов;
- Drag & Drop файлов;
- добавление файлов из папки;
- одновременная отправка на несколько касс;
- проверка доступности TCP-порта перед копированием;
- отдельный статус каждой кассы;
- журнал операций и отдельные log-файлы;
- встроенный `pscp.exe`, который автоматически извлекается при запуске.

## Требования

### Для запуска готового релиза

- Windows 10/11 x64.
- Устанавливать .NET Runtime не требуется: релиз собирается как self-contained приложение.

### Для сборки из исходников

- Windows 10/11 x64;
- .NET 8 SDK x64;
- PowerShell 5.1 или PowerShell 7+.

Проверка SDK:

```powershell
dotnet --version
```

## Сборка EXE

```powershell
.\Build_EXE.ps1
```

Готовый файл:

```text
publish\MoverGUI.exe
```

## Создание релизных бинарников

Например, для версии `1.0.0`:

```powershell
.\Create_Release.ps1 -Version 1.0.0
```

В каталоге `dist` будут созданы:

```text
MoverGUI-v1.0.0-win-x64.exe
MoverGUI-v1.0.0-win-x64.zip
SHA256SUMS.txt
```

Чтобы после сборки сразу создать GitHub Release:

```powershell
.\Create_Release.ps1 -Version 1.0.0 -Publish
```

Для публикации требуется установленный и авторизованный GitHub CLI (`gh`).

## Первый запуск

Если рядом с `MoverGUI.exe` находится старый `settings.ini`, программа может импортировать:

- `_send_to`;
- `_IPlist`.

Пароли из старого BAT-файла намеренно не импортируются. Их нужно добавить через окно **«Пароли»**.

## Настройки и логи

```text
%LOCALAPPDATA%\MoverGUI\settings.json
%LOCALAPPDATA%\MoverGUI\Logs\
%LOCALAPPDATA%\MoverGUI\bin\pscp.exe
```

Пароли в `settings.json` не хранятся открытым текстом: они защищены Windows DPAPI и привязаны к текущей учётной записи Windows.

## SSH host key

При первом подключении к новой кассе PSCP может сообщить, что ключ SSH-хоста ещё не сохранён. Mover GUI поддерживает подтверждение такого ключа и сохраняет его в кэше PuTTY текущего пользователя Windows.

## Безопасность

Приложение предназначено для администраторов и технических специалистов. Используйте его только для касс и серверов, к которым у вас есть разрешённый доступ.

В текущей исходной версии проекта находится PSCP 0.62, у которого известны исправленные в более новых версиях PuTTY уязвимости. Перед публичным производственным использованием рекомендуется заменить `MoverGUI/Resources/pscp.exe` на актуальную стабильную версию PSCP с официального сайта PuTTY и повторно протестировать передачу файлов.
